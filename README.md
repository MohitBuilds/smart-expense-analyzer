# 💰 Smart Expense Analyzer

A Python + MySQL + Streamlit web application for tracking, managing, and analyzing personal expenses.

## 🚀 Live Demo

👉 [Open Smart Expense Analyzer](https://smart-expense-analyzer-js3wmyuem88wofykfv2xre.streamlit.app/)

## ✨ Features

- 📊 Expense Dashboard
- ➕ Add Expenses
- ✏️ Edit Expenses
- 🗑️ Delete Expenses
- 📄 PDF Report
- 📈 Monthly Analysis
- 📥 Export Data
- 🗄️ MySQL Database
- ☁️ Cloud Database with Aiven
- 🌐 Deployed with Streamlit

## 🛠️ Tech Stack

- Python
- Streamlit
- MySQL
- Pandas
- Aiven
- Git & GitHub
